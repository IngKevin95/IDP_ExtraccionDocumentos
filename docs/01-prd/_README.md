# 01-prd/ — qué vive aquí

Carpeta del Product Requirements Document. Se genera con `/factory:prd` (standalone) o como primer tramo de `/factory:flujo`.

- **Nombrado**: normalmente un único PRD vigente por proyecto. Con módulos independientes, se permite dividir en `prd-<modulo>.md` (uno por módulo).
- **Chequeo obligatorio**: todo PRD debe cubrir los 12 componentes definidos en `~/factory-spec-driven-product/METODOLOGIA.md` §1 — sin excepciones antes de pasar a backlog.
