# 03-backlog/ — qué vive aquí

Dos artefactos conviven en esta carpeta:

| Archivo | Contenido | Cómo generarlo |
|---|---|---|
| `epicas.md` | Descomposición del PRD en épicas, con trazabilidad a objetivos | `/factory:epicas` |
| `backlog.md` | Tabla ordenada de historias (consume `docs/04-historias/`) | `/factory:backlog` |

**Regla dura**: el orden de las filas en `backlog.md` ES la priorización vigente — no es un detalle cosmético. Cada épica debe trazar a al menos un objetivo del PRD.
