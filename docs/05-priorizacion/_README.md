# 05-priorizacion/ — qué vive aquí

Registro histórico de sesiones de priorización, un archivo por sesión: `<framework>-YYYY-MM-DD.md` (ejemplo: `moscow-2026-05-20.md`).

- **Generación**: `/factory:priorizar`, eligiendo entre MoSCoW, RICE, Valor-Esfuerzo o Eisenhower.
- **Regla de completitud**: el framework elegido se aplica a todo el backlog, nunca parcial. Si el resultado deja casi todo en "Must" (MoSCoW), la sesión debe reabrirse — señal de que el framework no está discriminando.

Metodología completa: `METODOLOGIA.md` §7.
